# Legal Pages for GitHub Hosting

If you host these documents on GitHub, two easy options are:

## Option A: GitHub Pages (recommended)
1) Put these files in a public repo (or a private repo with Pages enabled).
2) Enable **Settings → Pages**.
3) Choose **Deploy from a branch** (usually `main` / `/docs` or root).
4) Use these URLs in your Discord Developer Portal:

- Terms of Service URL: `https://<your-user>.github.io/<your-repo>/TERMS_OF_SERVICE.html` (if using a static site generator)
- Privacy Policy URL: `https://<your-user>.github.io/<your-repo>/PRIVACY_POLICY.html`

If you are hosting as raw Markdown, consider using a simple static site generator (like GitHub Pages with Jekyll) so the pages render as nice standalone documents.

## Option B: Direct GitHub file links
Discord typically expects a normal webpage URL. Direct file links can work but are less reliable because they are not “page-like.” If possible, use GitHub Pages.
