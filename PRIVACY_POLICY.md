# Privacy Policy (Discord Bot)

**Last updated:** 2026-02-20

This Privacy Policy explains what information the Bot processes, how it is used, and your choices.

---

## 1. Overview

The Bot processes Discord-provided identifiers and Server event data to operate features like raffles, session/roster management, approvals, and notifications.

We do **not** sell personal data.

## 2. Information We Process

Depending on features used and Server configuration, we may process and store:

### 2.1 Discord Information
- Discord user ID
- Username / display name (as provided by Discord)
- Server (guild) ID
- Channel ID, role ID
- Message IDs and timestamps for Bot workflows (e.g., approvals, entries, roster updates)

### 2.2 Feature and Configuration Data
- Raffle configurations and entries (who entered, when, entry counts)
- Session/jump records (host, roster, verification state, timestamps)
- Insurance-request workflow records (request, claim/deny actions, which role/user claimed)
- Server settings (configured channels, toggles for announcements, etc.)
- User preferences (e.g., timezone, if the Bot supports per-user display)

### 2.3 Third-Party / Game API Data (If Used)
If enabled, the Bot may request limited third-party data necessary to provide verification or display features. For Torn-specific details, see **Torn API Disclosure and Disclaimer**.

The Bot is designed to request **only what is needed** for the feature being used.

## 3. How We Use Information

We use information to:

- Provide and maintain Bot features
- Prevent abuse, spam, and fraud (e.g., verification workflows)
- Provide operational/audit information to Server Admins (where applicable)
- Troubleshoot, debug, and improve reliability

## 4. Where Information Is Displayed

The Bot may post messages into Server channels configured by Server Admins. Those messages may include usernames, Discord IDs (sometimes implicitly), and event-related actions.

Once posted in Discord, message retention is controlled by Discord and Server Admins.

## 5. Sharing

We may share information only:

- Within your Server, where workflows are posted to configured channels
- With infrastructure providers necessary to run the Bot (hosting/database), under standard operational access

We do not sell personal data.

## 6. Retention

We retain data only as long as necessary for:

- operating the features you use
- abuse prevention and service integrity
- troubleshooting and dispute context

Retention may vary by feature and Server settings.

## 7. Security

We use reasonable security measures to protect stored data. No system can guarantee absolute security.

## 8. Your Choices and Requests

Depending on technical feasibility and our ability to verify identity, you may request:

- access to certain stored data about you
- deletion of certain stored data about you

Note: Bot-posted Discord messages are controlled by Discord/Server Admins and may not be removable by us.

Contact the Bot operator via the official support method advertised in Bot documentation.

## 9. Children

The Bot is not intended for users under 13 (or the minimum age required by Discord in your region). Do not use the Bot if you do not meet Discord’s age requirements.

## 10. Changes

We may update this Privacy Policy from time to time. Continued use of the Bot after updates means you accept the updated policy.

## 11. Contact

For privacy questions, contact the Bot operator via the official support method advertised in the Bot’s documentation or official Server.
